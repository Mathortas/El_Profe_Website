# El Profe — app

Frontend en React + TypeScript + Vite.

## Cómo correrlo

```bash
cd app
npm install
npm run dev
```

Abre la dirección que muestra la terminal (normalmente http://localhost:5173).

## Qué hay por ahora

- `src/design/`: el sistema de diseño (tokens, tema claro/oscuro, acento por selección y componentes).
- `src/styleguide/`: la guía visual que muestra cada pieza en vivo. Es lo que se ve al abrir la app.

## Dependencias de diseño

- Tipografía: Archivo (variable, con eje de ancho) vía `@fontsource-variable/archivo`.
- Íconos: `lucide-react`.
- Banderas: `flag-icons`.
